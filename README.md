# Sania Irshad — Interactive Portfolio

A responsive, dependency-free portfolio with a mathematical 4D tesseract projection, pointer interaction, project filters, keyboard-accessible course tabs, and reduced-motion support.

## Local preview

Run `python -m http.server 8000` in this directory, then open http://localhost:8000.

## Deploy on Vercel

Import this repository in Vercel. Select Framework Preset **Other**, leave Build Command empty, use repository root as Root Directory and `.` as Output Directory. No environment variables or packages are required.

## Content

Education and competencies are grounded in the supplied CV and current coursework. Projects link to the owner's GitHub repositories. No completed internship duties, performance claims, or commercial clients are invented. The stockout project is described as an academic prototype. The illustrative bars are not results. The fourth-dimensional object is a true 16-vertex, 32-edge hypercube projected through 3D to the screen.

Contact uses mailto and a copy-email button; no backend form is needed. Exact address, birth date, phone number, and the outdated CV download are omitted from the public site.
